Student Manager
Abeginner Business Central extension built with AL to manage students and their classes.
Features
Create and manage students
Create and manage classes
View students using list and card pages
view classes using list and card pages
Assign students to classes
Validate  student age
Check whether a student is an adult
Change student's class 
Use AL codeunits for reusable business logic
